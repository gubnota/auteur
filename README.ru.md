# MyMovie Studio

Версия **0.1.21**: Workflows, Generate, Jobs, Library, Renders, Instances, Search и Settings работают без открытого фильма. Фильм добавляет раскадровку и персонажей; его закрытие сохраняет общие ресурсы и выполнение заданий. Терминал принимает ввод с клавиатуры, агент показывает CPU, RAM и память GPU.

Добавлены неизменяемые примеры **FLUX.3 Klein T2I и I2I с двумя референсами**: варианты T4, RTX и Apple Silicon упакованы внутри каждого workflow. Выберите вариант перед инициализацией. [Примеры и зависимости](docs/WORKFLOW_EXAMPLES.md), [локальная установка агента](docs/LOCAL_COMFYUI_TEST.md). Загрузка моделей выполняется агентом; для FLUX нужны принятие лицензии и авторизация Hugging Face на узле. Генерация FLUX и облачный GPU пока не проверены.

**Быстрый запуск Colab:** откройте [актуальный блокнот](https://colab.research.google.com/github/gubnota/auteur/blob/main/deploy/colab/MyMovie_ComfyUI.ipynb), подключите CPU или GPU и выберите **Run all** без правок. Тестовые ключи уже заданы; агент/relay, закреплённая версия ComfyUI, браузер импорта и cloudflared устанавливаются автоматически. Скопируйте адрес relay и ID узла в Connections, включив polling временного туннеля. Модели и плагины workflow устанавливаются позже из Studio. Run all оставляет узел работать; остановка выполняется вручную. Старые копии в Drive не обновляются — откройте блокнот по ссылке.

**CPU-режим:** Colab и Kaggle по умолчанию используют `DEVICE = "auto"`: доступные CUDA GPU или один CPU-worker. `"cpu"` принудительно выбирает CPU, `"cuda"` требует заданное число GPU. Для проверки подключения и установки начните с mask canary без весов; генерация моделей на CPU может быть очень медленной. Откройте обновлённый блокнот заново: сохранённые копии не обновляются автоматически.

[Проверка соединения с вашего компьютера](docs/WORKFLOW_SETUP.md#test-the-notebook-connection-from-your-desktop): готовый Python-скрипт, desktop-токен и расшифровка HTTP-ошибок. У relay нет главной страницы: `/` и `/v1` возвращают 404.

Портативная киностудия для macOS: пакеты `.mymovie` в Finder, эпизоды и раскадровка, общие персонажи и материалы, повторное использование ComfyUI workflows и история заданий.

Версия исходников/приложения: **0.1.21**. [Опубликованные сборки v0.1.15](https://github.com/gubnota/auteur/releases/tag/v0.1.15) включают Linux-агент и соответствующий relay. Перед созданием тега зафиксируйте версии коммитом: git add только подготавливает изменения. Локальная macOS-сборка подписана ad-hoc; нотариализация и проверка запуска на остальных платформах ещё не завершены.

## Загрузка моделей и установка workflow

**Settings → Model downloads** сохраняет скрытый `HF_TOKEN` в системном хранилище. Сохранение, замена и удаление выполняются явно; открытие настроек не читает сохранённый ключ. Для gated-моделей сначала получите доступ на странице Hugging Face с того же аккаунта: токен не заменяет разрешение автора модели.

В **Workflows** выберите инстанс и нажмите **Install on instance → Dependencies**. После проверки **Install & prepare** устанавливает зависимости через агент и подготавливает тот же workflow без новой копии в каталоге. **Publish graph only** только сохраняет JSON графа в ComfyUI. Для установки файлов прямому подключению ComfyUI нужен агент.

У собственных workflow доступны **Inputs**, **Outputs**, **Dependencies**, **Guide**. Сначала подготовьте workflow на выбранном инстансе для обнаружения полей. Примеры доступны только для чтения; **Create editable copy** явно создаёт редактируемую копию.

Передача HF-ключа требует агента и relay **0.1.21** и личной пары desktop/agent-токенов. Ключ передаётся в памяти одному заданию и до получения истекает через десять минут; в задания, журналы и пакеты он не записывается. Локальные HF-ключи узла поддерживаются; пользовательские скрипты не получают desktop HF-ключ. Обновите удалённый клиент перед проверкой.


## Основной путь

1. **Workflows:** один раз импортируйте обычный ComfyUI JSON или API-граф. Выберите сохранённый узел и **Prepare inputs**. Обычный workflow преобразуется через frontend выбранного ComfyUI; оригинал неизменяемый.
2. **Inputs:** настройте названия и роли входов image/video/audio/text, Optional, Advanced и Hidden. Пустой optional-вход сохраняет исходное значение; необходимый файл должен существовать на узле.
3. **Outputs:** задайте подписи и выбирайте возвращаемые файлы для Library. Это не отключает выходные узлы самого графа.
4. **Dependencies:** укажите совместимость, ОС, архитектуру и precision. Разные графы Apple Silicon/CUDA/CPU импортируются отдельными вариантами общей семьи; смена флага не преобразует граф.
5. **Guide:** README в Markdown, иллюстрация и коллекция. Экспорт/импорт `.mymovie-workflow.json` переносит графы, формы и зависимости между фильмами; профили узлов и ссылки на секреты не переносятся.
6. **Generate:** выберите workflow/узел, назначьте материалы через галерею с поиском или drop, проверьте значения. Уже импортированные материалы используются по ID. **Add to queue** только ставит в очередь; **Run now** запускает.
7. **Jobs:** чекбоксы задач, **Run selected**, **Remove selected from queue**. Незапущенные задачи и их узлы редактируются через Generate → **Save queue changes**; исходные отменённые записи остаются. На одном узле FIFO, на разных — параллельно.

## Проекты и материалы

Создайте/откройте `.mymovie`, переименуйте эпизоды, организуйте сцены и кадры. Референсы персонажей общие; персонажи сцены наследуются кадрами. Реализованы кнопки импорта и обработка drop; автоматическая проверка настоящего Finder drop ещё открыта.

**Copy into movie** копирует материалы; **Keep original location** сохраняет внешнюю ссылку. Дедупликация по хешу. **Check files**, **Relink**, **Collect for export** сохраняют назначения. Перед переносом соберите внешние материалы и закройте фильм. Library/Renders используют одни ID, теги render и provenance. Trash/Restore сохраняет историю. Есть постеры видео и переходы к использованию в кадрах.

Схема **v5**: старые пакеты обновляются с явным подтверждением и резервной копией. Сохраните полный оригинал для старой версии приложения.

## Первый запуск узла

**Guide → Edit dependencies** открывает настройки источника и относительного пути моделей/плагинов. **Open source** открывает источник в браузере; итоговый путь виден до сохранения. Прямое подключение показывает подготовку workflow, установка и её журналы требуют агента. Общедоступные тестовые токены не обращаются к Keychain; для личных сохранённых ключей используйте **Load saved private tokens** или **Check connection**.

**Workflows → Dependencies → Complete setup script**: Mac/Linux/SSH, Colab и Kaggle. Выберите проверенный checksum агента нужной архитектуры, Python/папку своего ComfyUI и закреплённые источники моделей, LoRA, plugins и wheels. Управляемый узел устанавливает проверенные зависимости, запрашивает перезапуск и подготовку API-графа. Готовность подтверждается в текущем сеансе после проверки и canary; старый marker-файл недостаточен.

Приватный узел подключается исходящим соединением к HTTPS relay с аутентификацией. Его доступный адрес и ID worker указываются в Connections. [Полные инструкции](docs/WORKFLOW_SETUP.md), [Colab/RunPod/Kaggle](deploy/runpod/README.md), [проверки](docs/GENERATION_ACCEPTANCE.md). Живой cloud GPU/relay/S3 тест ещё не выполнен. Прямое соединение ComfyUI не устанавливает зависимости удалённо.

Начните с **64 × 64 mask canary**, без весов/plugins/GPU. Дополнительный u2netp требует проверенных весов, plugin и совместимых offline wheels; результат — изображение и маска.

**Settings → Node access** содержит `MYMOVIE_AGENT_TOKEN` и `MYMOVIE_DESKTOP_TOKEN` с вашими предопределёнными публичными тестовыми значениями. Свои значения сохраняйте в системное хранилище; кнопка копирования переносит настройки в Configure ноутбука. Чтение env/Secrets закомментировано. Новые подключения **Connections → Colab / Kaggle** используют desktop-токен. Для приватного узла замените оба публичных значения. Ноутбук запускает relay на своём `RELAY_PORT` и туннель через установленный `cloudflared`; включите **Temporary Cloudflare tunnel · polling only**, вставьте выведенные публичный адрес relay и ID узлов. ComfyUI остаётся локальным. Пользовательские токены не записываются в проект. Google/DeepSeek/OpenRouter — опциональная помощь с текстом; custom/fal generation пока только конфигурация. Исторические отключённые узлы сохраняются, но задания на них не отправляются. Неопределённая отправка требует сверки, без слепого повтора. Есть нативный прогресс, уведомления и очищаемые журналы.

[Команды сборки](README.md#build-and-checks), [CI и releases](docs/CI_RELEASES.md), [память проекта](docs/PROJECT_CONTEXT.md). GitHub/GitLab собирают macOS Apple Silicon, Windows x64, Linux x86_64 и агенты Linux x86_64/macOS Apple Silicon с relay. Linux ARM64 desktop включён только в GitHub. macOS Intel desktop/agent и Linux ARM64 agent закомментированы. Ноутбуки автоматически выбирают опубликованный релиз, включая prerelease, и проверяют SHA256; для собственного архива checksum нужен вручную. Архив v0.1.15 уже включает relay для Cloudflare. Windows-агент не поставляется. Лицензия Apache-2.0 OR MIT. [English](README.md) / [Français](README.fr.md).

## Примеры workflows

**Workflows → Examples · start here**: иллюстрированные проверка соединения, SD 1.5 T4
и лёгкое удаление фона. Откройте копию, выберите узел через **Run and install on**
внутри окна workflow, затем **Dependencies → Initialize on [instance]**. После проверки
загрузок нажмите **Install & prepare on [instance]**: агент установит зависимости,
при необходимости перезапустит управляемый свободный ComfyUI, подготовит и опубликует
workflow, проверит готовность. Дополнительные команды в notebook не нужны.
[Инструкция](docs/WORKFLOW_EXAMPLES.md). Нужен агент с guided setup (0.1.16 или новее);
обновление приложения не обновляет запущенный notebook. CI запускается только по тегу версии.
**Clear finished** скрывает завершённые, ошибочные и отменённые задания нижней очереди;
история Jobs и результаты Library сохраняются.

## Фоновая инициализация и удаление workflows

**Activity** показывает этапы, журнал, загрузку файлов и кнопки Cancel / Reconnect
из любого раздела, включая Welcome. Независимые узлы работают параллельно;
общий runtime Kaggle последовательно изменяет зависимости и переиспользует файлы.
**Move to Trash / Restore** удаляет и восстанавливает workflow с его настройками. **Trash → Clear trash** очищает список корзины, сохраняя исходные графы и историю заданий. Терминал занимает всё окно приложения.
В Setup доступен редактируемый многошаговый **Initialization recipe**. Терминал
агента и произвольные скрипты требуют личной пары токенов и явного включения.
[Инструкция](docs/NODE_ACTIVITY.md). Нужны агент и relay **0.1.21**;
последний опубликованный агент пока v0.1.15. Обновление приложения не обновляет notebook.
