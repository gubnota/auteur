# MyMovie Studio

Портативная киностудия для macOS: пакеты `.mymovie` в Finder, эпизоды и раскадровка, общие персонажи и материалы, повторное использование ComfyUI workflows и история заданий.

Версия исходников/приложения: **0.1.12**. [Опубликованные сборки](https://github.com/gubnota/auteur/releases/tag/v0.1.6) пока **v0.1.6**. Локальная macOS-сборка подписана ad-hoc; нотариализация и проверка запуска на остальных платформах ещё не завершены.

## Основной путь

1. **Workflows:** один раз импортируйте обычный ComfyUI JSON или API-граф. Выберите сохранённый узел и **Prepare inputs**. Обычный workflow преобразуется через frontend выбранного ComfyUI; оригинал неизменяемый.
2. **Inputs:** настройте названия и роли входов image/video/audio/text, Optional, Advanced и Hidden. Пустой optional-вход сохраняет исходное значение; необходимый файл должен существовать на узле.
3. **Outputs:** задайте подписи и выбирайте возвращаемые файлы для Library. Это не отключает выходные узлы самого графа.
4. **Setup:** укажите совместимость, ОС, архитектуру и precision. Разные графы Apple Silicon/CUDA/CPU импортируются отдельными вариантами общей семьи; смена флага не преобразует граф.
5. **Guide:** README в Markdown, иллюстрация и коллекция. Экспорт/импорт `.mymovie-workflow.json` переносит графы, формы и зависимости между фильмами; профили узлов и ссылки на секреты не переносятся.
6. **Generate:** выберите workflow/узел, назначьте материалы через галерею с поиском или drop, проверьте значения. Уже импортированные материалы используются по ID. **Add to queue** только ставит в очередь; **Run now** запускает.
7. **Jobs:** чекбоксы задач, **Run selected**, **Remove selected from queue**. Незапущенные задачи и их узлы редактируются через Generate → **Save queue changes**; исходные отменённые записи остаются. На одном узле FIFO, на разных — параллельно.

## Проекты и материалы

Создайте/откройте `.mymovie`, переименуйте эпизоды, организуйте сцены и кадры. Референсы персонажей общие; персонажи сцены наследуются кадрами. Реализованы кнопки импорта и обработка drop; автоматическая проверка настоящего Finder drop ещё открыта.

**Copy into movie** копирует материалы; **Keep original location** сохраняет внешнюю ссылку. Дедупликация по хешу. **Check files**, **Relink**, **Collect for export** сохраняют назначения. Перед переносом соберите внешние материалы и закройте фильм. Library/Renders используют одни ID, теги render и provenance. Trash/Restore сохраняет историю. Есть постеры видео и переходы к использованию в кадрах.

Схема **v5**: старые пакеты обновляются с явным подтверждением и резервной копией. Сохраните полный оригинал для старой версии приложения.

## Первый запуск узла

**Workflows → Setup → Complete setup script**: Mac/Linux/SSH, Colab и Kaggle. Выберите проверенный checksum агента нужной архитектуры, Python/папку своего ComfyUI и закреплённые источники моделей, LoRA, plugins и wheels. Управляемый узел устанавливает проверенные зависимости, запрашивает перезапуск и подготовку API-графа. Готовность подтверждается в текущем сеансе после проверки и canary; старый marker-файл недостаточен.

Приватный узел подключается исходящим соединением к HTTPS relay с аутентификацией. Его доступный адрес и ID worker указываются в Connections. [Полные инструкции](docs/WORKFLOW_SETUP.md), [Colab/RunPod/Kaggle](deploy/runpod/README.md), [проверки](docs/GENERATION_ACCEPTANCE.md). Живой cloud GPU/relay/S3 тест ещё не выполнен. Прямое соединение ComfyUI не устанавливает зависимости удалённо.

Начните с **64 × 64 mask canary**, без весов/plugins/GPU. Дополнительный u2netp требует проверенных весов, plugin и совместимых offline wheels; результат — изображение и маска.

Секреты храните в Keychain/Notebook Secrets. Google/DeepSeek/OpenRouter — опциональная помощь с текстом; custom/fal generation пока только конфигурация. Исторические отключённые узлы сохраняются, но задания на них не отправляются. Неопределённая отправка требует сверки, без слепого повтора. Есть нативный прогресс, уведомления и очищаемые журналы.
